SALONE FARMERS MARKET - HTML/CSS PROJECT

FILES
- index.html: Home page
- marketplace.html: Marketplace listings
- market-prices.html: Market prices table
- produce-details.html: Produce details page
- farmers-cooperatives.html: Farmers and cooperatives
- services.html: Services
- about.html: About page
- contact.html: Contact page
- style.css: Shared responsive styling
- images/: Illustrations used across the pages 

HOW TO RUN
1. Open index.html in a browser, or use the Live Server extension.
2. Keep style.css and the images folder in the same folder as the HTML files.

IMPORTANT
- This project uses HTML and CSS only. There is no JavaScript.
- Search, dropdown filters and sorting are visual controls only; they do not dynamically filter content.
- Price entries are placeholders and must be replaced with verified market data.
- Update the site name and contact details to match your final assignment brief.
